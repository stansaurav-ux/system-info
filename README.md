# System Info Tool

A Python script that displays system information at a glance.

## Features
- Username
- Current working directory
- Operating system
- Current date and time
- Python version
- Hostname
- Disk usage
- Memory usage
- Local IP address

## Requirements
- Python 3
- psutil (`pip install psutil --break-system-packages`)

## Usage
\`\`\`bash
python system_info.py
\`\`\`
